# Opensource ToDo

[English](readme.md) | Русский

Неофициальный, бесплатный и открытый настольный клиент Microsoft To-Do для Linux (установщик для Windows собирается в CI).

Opensource ToDo продолжает проект [Kuro](https://github.com/davidsmorais/kuro) [Дэвида Морайса](https://davidmorais.com), который в свою очередь продолжал [Ao](https://github.com/klaussinani/ao) [Клауса Синани](https://github.com/klaussinani). Оба проекта перестали развиваться, и этот форк поддерживает приложение в рабочем состоянии и добавляет то, о чём просили пользователи. Заслуга за исходную работу, логотип и иконки принадлежит им, см. раздел [Благодарности](#благодарности).

## Возможности

- Веб-приложение Microsoft To-Do в полноценном окне: значок в трее, автозапуск, запуск свёрнутым, глобальные горячие клавиши (X11), поверх всех окон, один экземпляр
- **Темы списков**: семь цветов (насыщенных или светлых) или восемь сцен, отдельно для каждого списка и для «Моего дня»; панель выбора выезжает справа так же, как настройки самого To-Do
- **Следовать цветам списка**: вид списка и его пункт в боковой панели окрашиваются в палитру, которую To-Do назначил списку
- **Следовать теме системы**: светлая и тёмная тема переключаются вместе с системой; **пользовательская тема** с редактируемыми цветами
- **Окно настроек** с системными элементами управления (общие, внешний вид, горячие клавиши) плюс редактируемый `todo.json`
- **Локализация**: английский и русский для меню, трея и диалогов; выбранный язык применяется и к самому веб-приложению To-Do
- Открытие последнего списка при запуске, масштаб от 50 до 300 %, горячие клавиши на всё (см. `Справка > Горячие клавиши`)
- Проверка обновлений через GitHub Releases
- Нативный Wayland (Electron 44): чёткое масштабирование на HiDPI, правильная иконка приложения и уведомлений

## Установка

Скачайте пакет для своего дистрибутива со [страницы релизов](https://github.com/fildunsky/opensource-todo/releases/latest): `.deb`, `.rpm`, `.pacman`, `.AppImage`, `.snap`, `.flatpak` или установщик для Windows. Каждый пуш в `master` также собирается в GitHub Actions, пакеты прикрепляются к запуску как артефакты.

```
sudo apt install ./todo-desktop_<версия>_amd64.deb
```

Исполняемый файл называется `todo-desktop`.

### Переход с Kuro

Opensource ToDo хранит профиль в `~/.config/Opensource ToDo/` (по спецификации XDG). При первом запуске он копирует профиль Kuro из `~/.config/Kuro/`, если тот есть: настройки, темы списков, положение окна и горячие клавиши переезжают вместе с ним. Файл `~/.kuro.json` из совсем старых версий тоже мигрирует. Если сессия Microsoft не сохранится, войдите в аккаунт ещё раз: Chromium шифрует её ключом, привязанным к имени приложения.

### Wayland

На сессии Wayland Electron 44 сам выбирает нативный Wayland. Чтобы принудительно задать бэкенд:

```
ELECTRON_OZONE_PLATFORM_HINT=x11 todo-desktop
```

Глобальные горячие клавиши работают только на X11.

## Настройки

`Файл > Настройки…` открывает окно настроек. Расширенные значения (цвета пользовательской темы, горячие клавиши) лежат в `~/.config/Opensource ToDo/todo.json`, окно настроек умеет открыть его в редакторе. Как добавить перевод, написано в [contributing.md](contributing.md), как собрать пакеты самостоятельно, в [docs/build-instructions](docs/build-instructions/index.md).

## Горячие клавиши

`Справка > Горячие клавиши` показывает текущие сочетания, их можно менять в окне настроек. По умолчанию на Linux и Windows используется `Ctrl`, на macOS `Cmd`.
